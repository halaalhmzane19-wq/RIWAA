# RIWAA | رِواء

تطبيق تعليمي تفاعلي قائم على الاسترجاع من قاعدة معرفة محددة المصادر.

## التشغيل

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## الذكاء الاصطناعي

يعمل التطبيق محليًا من قاعدة المعرفة إذا لم يوجد مفتاح API.
لتمكين طبقة RAG بالذكاء الاصطناعي، أضف `OPENAI_API_KEY` إلى Streamlit Secrets أو متغيرات البيئة.

## مبدأ السلامة

- لا إجابة من خارج المواد المسترجعة.
- إظهار المصدر عند توفره.
- امتناع عند نقص الدليل.
- لا فتوى شخصية أو حكم فردي.
- فصل النص المنقول عن الشرح المولد.
